# Trips

个人旅行攻略站，使用 GitHub Pages 托管。

## 站点

- 首页：`https://diyigelieren.github.io/Trips/`
- 川西 4 天 3 晚：`https://diyigelieren.github.io/Trips/trips/chuanxi-4d3n/`

## 目录结构

```text
Trips/
├── index.html
├── trips.json
├── README.md
└── trips/
    └── chuanxi-4d3n/
        └── index.html
```

新增攻略时，在 `trips/<trip-id>/index.html` 新建页面，并在 `trips.json` 中增加一条元数据记录即可自动出现在首页。
